# 3분 시연

[실제 포크 실행 화면을 편집한 영상](agents/agent-d/fork-demo.mp4). 1440×960 MP4, 180초, 한국어 자막. 장면은 브라우저에서 각 작업이 완료된 시점의 화면으로 구성한다. 실제 지갑 확장 팝업 대신 Playwright 테스트 provider가 일회용 Anvil 계정의 요청을 전달했다.

| 시간 | 화면과 설명 |
|---|---|
| 0:00–0:16 | WHSK/USDT 30일 관측, 거래 규모와 간격 |
| 0:16–0:42 | 매수자 B의 600 WHSK 사전 주문, 지갑 서명과 DB 등록 |
| 0:42–1:09 | 매도자 A의 1,000 WHSK 즉시 주문, 승인 상한과 두 서명 |
| 1:09–1:45 | 워커 이벤트, 600 직접 + 400 DEX 원자적 정산, 포크 영수증 |
| 1:45–2:17 | 같은 수량 기준 비교와 경제성 부족 시 토큰 미이동 |
| 2:17–2:46 | 조건부 fallback과 복수 주문별 토큰 변화량 |
| 2:46–3:00 | HSK 단일 풀 설계와 운영비·수요 검증 범위 |

세 역할은 매도자, 매수자, 전송 수수료를 부담하는 운영자다. 추가 테스트 매수자도 준비한다. 사용자 조건·서명·토큰 이동이 모두 연결된 기록은 [브라우저 포크 증거](agents/agent-d/browser-fork.json)에 있다. 같은 영상을 만들려면 새 `make dev-fork` 세션에서 `make record-demo`를 실행한다. 새 임시 지갑과 nonce를 사용하므로 해시는 달라진다.

메인넷 시연 시에는 팀장이 배포 주소와 당일 지출 예산을 승인하고 실제 경제성 및 유효한 주문을 확보해야 한다. 실제 메인넷 영수증과 Blockscout 링크는 그때 제출한다. 현재 영상은 포크 녹화이고 사용자 수요는 합성이다.
